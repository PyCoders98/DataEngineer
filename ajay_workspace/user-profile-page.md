# **Order Placement Guide**  

This guide provides step-by-step instructions for placing an order on the platform.  

## **1. Map Selection**  
- The map interface allows users to select the area of interest.  
- Zoom in/out using the `➕` and `➖` icons to refine the selection.  
- The selected area is highlighted in blue.  

## **2. Order Options**  
Users must configure the following options before placing an order:  

### **Projection**  
- Choose between `UTM` or `Geographic` projection.  
- Click `Apply` to confirm the selection.  

### **Processing Level**  
- Options include:  
  - `Raw`  
  - `Standard default` (selected by default)  
- Click `Apply` to confirm the selection.  

### **Datum & File Format**  
- Select `Datum`: Default is **WGS84**.  
- Choose `File format`: Default is **GeoTIFF**.  

### **Delivery Method & Market Sector**  
- Select a `Delivery method` (e.g., **CD/DVD**).  
- Choose a `Market sector` from the dropdown.  

### **Subsidy Type**  
- Select `Subsidy type requested` (e.g., **Institution Research**).  
- The assigned user and subsidy type appear below.  

### **Uses of the Data**  
- Users must specify the intended use of the data.  

### **Notes**  
- Additional comments or instructions can be entered in the provided text box.  

## **3. Product Details**  
- The table displays the selected product details:  
  - **Product name**  
  - **Date** of acquisition  
  - **Cloud cover percentage**  
  - **Projection type**  
  - **Processing level**  
  - **Cost (if applicable)**  
- Users can remove an item by clicking the **trash icon**.  

## **4. Placing the Order**  
- After configuring all options, click the **"Order Now"** button to finalize the request.
